# BMI Calculator

## About the Project

This is a simple BMI Calculator created as part of my web development internship.

The project allows users to enter their height and weight and calculates their BMI. It also displays the corresponding BMI category.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Height input
- Weight input
- BMI calculation
- BMI category display
- Validation for empty values
- Validation for zero and negative values
- Responsive design
- Simple and clean interface

## BMI Categories

- Underweight
- Normal weight
- Overweight
- Obesity

## What I Learned

Through this project, I practiced handling form inputs, JavaScript calculations, functions, if/else conditions, input validation, and displaying results dynamically.

## Project Outcome

The BMI Calculator successfully calculates BMI based on the user's height and weight and displays the appropriate category.
